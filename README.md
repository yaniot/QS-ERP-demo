# QS ERP · 静态演示站

**在线体验：** https://yaniot.github.io/QS-ERP-demo/

给创客、个人工作室和小型硬件团队的本地优先 ERP —— 这个仓库只放**打包好的静态演示站**，不含任何源码或真实数据。

> Static demo build of QS ERP. No source code, no real data, no backend.

## 这是什么

- 纯静态文件（HTML + JS + CSS），没有任何服务端、数据库或网络请求
- 所有数据都是**虚构的演示样例**：18 个元器件、3 个项目、2 张采购单、6 笔出货
- 接口由浏览器内的假后端应答（`/api/*` 被本地拦截），写操作只存在内存里，**刷新页面即还原**
- 顶部横幅的「重置数据」可以立刻回到初始状态

## 能看到什么

| 模块 | 内容 |
| --- | --- |
| 仓库概览 | 物料数量 / 库存价值 / 低库存、经营速览、计划提醒、最近入库 |
| 项目空间 | 3 个演示空间 → 文件 → 项目物料 → 产品版本、多级 BOM、成本试算、采购闭环 |
| 物料仓库 | 18 个虚构元器件，可按分类、库位、品牌筛选搜索 |
| 库位管理 | 区-架-层-盒编码、库位内物料清单、扫码定位（演示里没有真实扫码） |
| 经营看板 | 本月出货 / 销售额 / 毛利 / 库存资金、近 6 个月趋势、按项目销售 |
| 项目计划 | 计划卡片、逾期提醒、工时记录 |
| 系统设置 | 使用说明（可搜索的功能地图）、角色与账号（演示） |

## 演示里不能做什么

- **扫码 / 拍照识码**：需要摄像头与后端解析，演示站不支持
- **联网查料号**：没有后端，无法抓取供应商参数
- **文件上传、Git 提交 / 推送**：需要真实的项目空间仓库
- **AI 助手、OCR、云端备份**：需要服务端与密钥

## 想用完整版

源码在私有仓库维护。完整版是单进程 Node 应用，本地一行命令即可跑起来：

```bash
npm install && npm run dev     # http://localhost:4317
```

功能清单与部署方式见主仓库的 README 与 `docs/DEPLOY.md`。
